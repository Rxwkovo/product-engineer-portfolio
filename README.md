# Product Engineer Portfolio

Four truthful portfolio pieces built around product finishing work: practical UI, clear review steps, responsive implementation, and small workflows that can be inspected.

| Project | Type | What it demonstrates |
| --- | --- | --- |
| [Code Pet](code-pet/contra-entry.md) | Personal Project | Real Windows desktop companion, interaction design, iterative product refinement. [Source](https://github.com/Rxwkovo/Codex-Usage-Pet). |
| [AI-Assisted Product Intake](ai-product-intake/README.md) | Personal Project / Demo | Natural language to structured brief, human edit and confirmation, optional model-backed output. |
| [Smart Data Automation](smart-data-dashboard/README.md) | Personal Project / Demo | CSV/Excel upload, deterministic cleaning, field detection, preview and export. |
| [Modern Business Web](modern-business-web/README.md) | Personal Project / Demo | Responsive SaaS presentation adapted from an MIT-licensed template. |

Each directory includes a Contra-ready `contra-entry.md`, one `cover.png`, and four or five interface captures. The new demos include runnable source. The Code Pet case uses actual preview assets from its existing public source repository. Captures use sample data, and the fictional business concept is clearly labelled.

## Honest scope

- AI Intake screenshots show a local rule-based parser. A model-backed path is implemented but not verified without an API key.
- Smart Data Automation sample values are fictional. Cleaning rules are deterministic and described in its README.
- Northstar is a fictional product. Its pricing is illustrative and there is no transaction flow.
- No client delivery, commercial outcome, or years of experience are implied.
