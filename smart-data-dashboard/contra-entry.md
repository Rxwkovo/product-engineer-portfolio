# Smart Data Automation Dashboard

- **Project type:** Personal Project / Demo
- **Role:** Workflow design, Python API development, dashboard UI
- **Skills:** Python, FastAPI, pandas, Excel, CSV, data cleaning, responsive UI
**Project link:** https://github.com/Rxwkovo/product-engineer-portfolio/tree/main/smart-data-dashboard

## Description (131 words)

Smart Data Automation is a personal demo that gives a common spreadsheet cleanup task a clear, usable interface. A user uploads a CSV or Excel file, and the dashboard detects the columns, summarizes missing data, trims whitespace, removes duplicate rows, fills missing text and numeric values, and standardizes recognizable date fields. It then shows the changes in a concise report, previews the cleaned rows, and offers a CSV export. I built the FastAPI endpoint and pandas processing pipeline alongside a responsive dashboard so the workflow feels like a small product rather than a one-off script. A fictional sample dataset makes the behavior easy to inspect without uploading private data. The rules are visible and deterministic, and the README explains their limits so users can review the output before relying on it.
