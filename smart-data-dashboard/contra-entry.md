# Prism - Smart Data Automation Dashboard

- **Project type:** Personal Project / Demo
- **Role:** Workflow design, Python API development, dashboard UI
- **Skills:** Python, FastAPI, pandas, Excel, CSV, data cleaning, responsive UI
- **Project link:** https://github.com/Rxwkovo/product-engineer-portfolio/tree/main/smart-data-dashboard

## Description

Prism is a personal spreadsheet automation demo designed to make cleanup decisions visible. Users upload a CSV or Excel file, or choose a fictional sample, and receive a report of deterministic processing rules. The Python and pandas pipeline trims text, removes identical rows, fills missing values, and standardizes recognizable dates. A FastAPI endpoint returns detected fields, actual rule counts, original and cleaned sample rows, and a CSV export. A scroll-driven product story introduces the idea; the working interface focuses on understanding what changed before downloading. The report separates whole-file counts from eight-row previews and explains that samples are not row-aligned after duplicate removal. Unparseable dates and the limits of automatic filling are disclosed. Files are processed in memory and are not stored on the server. The project demonstrates a small, inspectable automation product with English copy and responsive UI, without implying customer delivery or commercial results.
