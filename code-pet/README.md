# Code Pet - Interactive Desktop Companion

**Personal Project.** The real Windows application is [Codex Usage Pet](https://github.com/Rxwkovo/Codex-Usage-Pet). This portfolio adds a separate, runnable browser interface exploration in `prototype/`.

## Open the prototype

Open `prototype/index.html`, or serve that directory using a local static server. No dependencies or account connection are required.

The prototype uses the existing approved mascot artwork. It demonstrates compact/expanded views, five illustrative mood/data states, separately labelled five-hour and weekly usage windows, and a reduced-motion control. All values are sample data. It does not read a real account or run as a Windows overlay.

## Design and assets

The idea is peripheral presence: a small companion stays near the workspace and expands into precise information on request. Mint follows the approved character. All controls and content are English. Body text and small labels use locally bundled Bricolage Grotesque; headings retain their original treatment.

Prototype code is MIT licensed. Approved preview artwork comes from the original release; its copyright and MIT license are retained in `prototype/ARTWORK-LICENSE.txt`. The font retains its SIL OFL 1.1 license in `prototype/OFL-Bricolage.txt`.

The JPGs are captures of the browser exploration. Existing PNGs document the Windows product and its settings.
